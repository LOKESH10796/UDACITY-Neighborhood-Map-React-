A modern, responsive, and highly interactive neighborhood map application built with React, TypeScript, and Vite. This application integrates with third-party mapping and location APIs (like Google Maps or Foursquare) to help users discover, filter, and explore venues in a targeted neighborhood.

## ?? Key Features

*   **Interactive Map:** Renders a responsive map with interactive markers.
*   **Search & Filter:** Instantly filter map markers and list items via text input.
*   **Location Details:** Click on a marker or list item to fetch and display third-party data (e.g., photos, ratings).
*   **PWA Ready:** Built as a Progressive Web App (PWA) with offline capabilities using Service Workers and \ite-plugin-pwa\.
*   **Accessibility:** ARIA-compliant and fully keyboard navigable.

## ??? Architecture

*   **React:** Component-based architecture for UI and state management.
*   **Vite:** Ultra-fast bundling and Hot Module Replacement (HMR).
*   **TailwindCSS:** Utility-first styling for rapid, responsive design.
